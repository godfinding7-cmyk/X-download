Frequently asked questions

Quick answers for common downloader questions.

Can I download Twitter/X GIFs? +

Yes, if the post is public and your media extraction backend returns the GIF/video source. X commonly serves animated GIFs as video files, so they are often downloaded as MP4.

Does it work on Android and iPhone? +

The website interface is fully responsive. Actual file-saving behavior can differ slightly between browsers and operating systems.

Can private posts be downloaded? +

No. This page is intended for publicly accessible posts and media that you have permission to save.

Why does the website need an API/backend? +

Browsers usually cannot directly extract X media because of platform restrictions, CORS and changing media URLs. A server-side extractor or authorized API is therefore needed for reliable downloads.

Is TweetSave affiliated with X or Twitter? +

No. TweetSave is an independent utility and is not affiliated with, endorsed by, or sponsored by X Corp.

Can I repost a downloaded video? +

Does TweetSave store my X password? +

No X password is requested by this interface. You should never enter your X password into the post URL field.

About TweetSave

TweetSave is a browser-based utility designed to make it easier to save media from publicly accessible X/Twitter posts when you have the right to download that content. It does not require an X password and it does not provide access to private accounts.

The service is intended for practical uses such as saving your own uploads, keeping a personal copy of media you have permission to use, or downloading material released for reuse by its owner.

What this tool can do

  • Process supported public X/Twitter post links.
  • Show available video qualities returned by the server.
  • Save supported video or GIF media as downloadable files.
  • Work from modern Android, iPhone, tablet and desktop browsers.

How to save an X/Twitter video on your phone or computer

Open the public post containing the media you are allowed to save, use the Share option in X to copy the post link, paste that URL into TweetSave, and choose one of the available video qualities. On Android and desktop browsers, the file normally appears in the Downloads folder. On iPhone, the browser may first place the file in Files, where it can be saved or shared further.

Why a download may fail

A post may be private, deleted, age-restricted, region-restricted, temporarily unavailable, or X may have changed how the media is delivered. A failed request does not necessarily mean there is a problem with your phone. Try a different public post you are authorized to save and make sure the copied link contains /status/.

Video and GIF formats

X often delivers animated GIF posts as video streams, so a GIF may be offered as an MP4 file. Available resolution depends on the source post and on the formats X makes available for that media.
